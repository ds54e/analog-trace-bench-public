# 読みやすいアナログ回路図の判断基準

ここでいう「人間らしい」は筆跡ではなく、読む人が知っている回路の型を使って動作を伝えること。以下は作例の観察をもとにした作図方針であり、学会・EDAの公式規格でも、測定済みの可読性指標でもない。ギャラリーの具体例と出典は `gallery-evidence.md` に記録する。

## 1. 接続表ではなく、動作の構造を配置する

- 素子を置く前に、差動対、電流ミラー、カスコード、出力段、バイアス、補償、検出・帰還を見つける。認識できない部分は推測を断定しない。
- 一つの機能をつくる素子を近づけ、別の機能との間に一段大きな余白を置く。グループ名がなくてもまとまりが見える配置を目指す。
- 長い見出しや色枠で、悪い配置を補おうとしない。囲みは独立したCMFB・バイアス・クロックなど、切り分ける意味がある範囲に限定する。

**確認：** まず図を縮小し、入力対・主増幅部・出力・補助回路の位置を短時間で指せるか。これは人によるレビューの目安であり、自動合格判定ではない。

## 2. 差動対とミラーは「見慣れた形」を優先する

- 対となるMOSは同じ高さ・同じ表示寸法に置き、ソースの共通接続を短くまとめる。対応する負荷・カスコードも行を揃える。
- 入力ゲートを外側へ向けると、二つの入力と左右枝が分かりやすい場合が多い。部品記号を鏡像にしても、電気的D/G/S/Bを入れ替えない。
- ミラーの基準側とコピー側を近づけ、共通ゲートを一本の短い線で示す。基準側のD–G接続は小さな局所ループにする。
- 左右の線長・曲がり方を揃えて対応関係を表す。ただしサイズ・負荷・接続に実際の差がある回路を、同一回路のように見せない。
- 正入力を必ず左、負入力を必ず右にする決まりはない。元の入力極性、出力の取り方、帰還の向きを保ったうえで、左右の読み順を選ぶ。

**悪い兆候：** 差動対が遠く離れる／共通ソース点から両枝への線が不釣り合いに長い／ミラーの片側だけ別ブロックに見える。

## 3. 電源・電流の縦方向と、信号の読み順をつくる

- 標準的な単電源回路では高電位側を上、低電位側を下とする。直列の電流経路を縦列にし、対応する素子段を横に揃える。
- 単端の多段回路は入力→増幅→出力を左から右に置くことが多い。差動・折返し・リング・クロス結合回路では、局所対称性やループ構造の方が優先される。
- PMOSだから常に上、NMOSだから常に下と機械的に置かない。高側のNMOS、低側のPMOS、スイッチ、ボディ駆動、負電源回路などは実際の端子関係に従う。
- 電源レールは関連する枝の範囲に留める。離れた補助回路まで巨大な四角いレールで囲う必要はない。レールを分割する場合は同一ネット名とスコープを明示する。

## 4. 図を読む理由になる接続は、線で残す

**優先して連続配線するもの：** 差動対の共通点、局所ミラー、段間の主信号、位相補償の接続先、LDOの主要な検出・帰還経路。

**ラベル化しやすいもの：** 多数箇所へ配る電源、離れた補助ブロックのバイアス、クロック、複数ページ間の信号。同名・大文字小文字・階層スコープの扱いをツールと照合する。

- ラベルを減らすために何本も長い横断線を引くことも避ける。「主要な経路を追う際の、同名ラベル探し」を先に減らす。
- 主経路と帰還の区別は配置で示し、必要なら落ち着いた一色を補助的に使う。色を消しても接続と機能を読めること。
- このユーザーの作図方針：接続する十字は、点が重ならない最小限のずれを付けた二つのT字分岐へ分ける。上からの枝と下からの枝を同じ位置へ集めない。ただし微小な分岐のずれを、部品間の大きな距離へ拡大しない。LDOの分圧器は抵抗を同じ縦列に置き、CFFの接続と帰還線の取り出し位置だけを少しずらす案を優先する。点は補助とし、接続／非接続を形でも判別できるようにする。異なるネットの非接続交差をT字にしてはならない。非接続交差は配置変更で減らし、残す場合は図全体の規約を統一する。
- 十字の交差と接続点を混同させない。接続は明瞭な点／T分岐、非接続は点なし交差など、ツールの一貫した規約に従う。斜め線は原則抑えるが、対称なクロス結合の対応を明確にする短い斜め線は例外となる。
- 帰還先を読める形を保ったうえで、不要な曲げは削る。「機能を追える」は迂回を残す理由にはならない。段間の高さ・端子の向き・分岐位置を見直し、文字が邪魔ならまず文字を移す。具体的な手順は [配線の簡素化](routing-refinement.md) を読む。

### OTAの補償

入力段出力と最終出力、または別の正しい補償ノードの間にRC枝を配置する。補償枝がどの段をまたぐか一目で分かる位置に置く。主信号線に近接した平行線として埋もれるなら、ゲート側から出力側へ回る独立した枝として間隔を取り直す。縦のRC枝や上／下側の戻り経路を比較し、取り出し点をT字に分散する。横向きの補償枝を一律に禁止せず、両端とまたぐ増幅段が明瞭かで判断する。直列R/Cの順序や途中ノードを見栄えのために変更しない。飛越し補償・電流バッファ付き補償を単純なMiller容量と決めつけない。

### LDOの帰還

出力を右、分圧器をその下、誤差増幅器を左寄りに置く構成から検討する。VOUT→分圧点→誤差増幅器→ゲート駆動→パス素子の経路が追えるように、帰還線用の通路をあらかじめ確保する。

最終段が横長なら、まずパス素子のドレインと分圧抵抗2個を同じ縦列に重ねる案を試す。CFFは上側抵抗の隣へ置き、出力端子はその先の短い延長にする。パス素子・分圧器・CFFをそれぞれ遠い独立列に置かない。適応バイアス回路などの端子対応は保持する。CFFとFBの取り出し位置は最小限だけずらし、抵抗列を折り曲げない。これは配置候補であり、異なる回路のトポロジーをこの形へ変更してはならない。

帰還線をすべて下端に通すことは絶対条件ではない。PMOS入力対の入力位置、ボディ接続、補助ループとの交差を見て外周や段間の通路を選ぶ。明示配線で著しく混雑する場合はラベル接続にし、その切断箇所と同名の接続先を近く示す。

出力連動バイアスの抵抗は、上側ミラーのD–G結線へ差し込まれたように見える横断線に注意する。まず元ネットリストで両端を確認する。例えば `RB VOUT NB` と `XMB NB NB VSS VSS` なら、XMBのダイオード接続点NBへの接続は正しく、別のミラーのダイオード点D1とは区別する。RBを出力側の空いた場所へ移し、NBの名前と戻り線を見せる案を比較する。見た目の違和感を理由に接続を変更しない。

同じNBネット内でも、帰還線の合流位置は機能が伝わるように選ぶ。このユーザーの指定では、RBからの戻り線はRSとXMBドレインを結ぶ縦の幹線へ直接合流させ、XMBのD–G接続用の横枝には合流させない。D–G枝は幹線の少し下から独立して取り出す。電気的に同じノードだからどこへ差し込んでもよい、と見た目の指摘を片付けない。既存例では二つの取り出し点を10描画単位だけ離し、部品移動や横幅の増加なしに描き分けた。

その際も抵抗の位置を固定して帰還線を折り返さない。出力側の取り出し点、RB、RS–XMBの幹線上の合流点を同じ高さにそろえられるなら、一本の水平経路を優先する。D–G枝と分離することは、RBを下段へ移して大きな迂回を作る理由にはならない。横抵抗の文字が上の制御線と競合するなら、名前と値の2行をまとめて下へ移す。経路を曲げる前に部品と文字を動かす案を試す。

## 5. 余白は「関係の強さ」を示すために使う

- 余白ゼロと、等間隔に広く散らす配置の両方を避ける。密接な局所ループは小さく、機能間の余白は少し広くする。
- 記号そのものを尺度にする。初期配置の目安として、素子行間は記号高の約1.5〜2.5倍、差動枝の間隔は記号幅の約2〜4倍から試す。これは作業開始用の仮値で、ラベルの実寸と配線経路を見て調整する。固定ピクセル値を異なるレンダラーへ流用しない。
- 余白の見直しでは、作例の同じ機能単位を目視比較する。分圧器の上下抵抗、差動対と負荷、補償RCをそれぞれ一組として近づけ、文字・値の領域を残す。画面全体の白い面積や均一な素子間隔を目標にしない。
- 大きな紙面に合わせて間隔だけ広げない。まず適切な密度の回路を作り、外周をトリミングし、必要なら詳細図へ分ける。
- このユーザーは、文字のない場所にも一律の余白を残す配置を好まない。特にLDOは、バイアス・誤差増幅器・補償・パス素子・分圧器の列を並べるだけで横長になりやすい。各隙間に実際の文字幅、線の通路、機能の区切りのどれが必要かを確認し、根拠のない隙間はグリッド単位で詰めて再描画する。横幅を縮める際は文字縮小や画像の横圧縮を使わない。対になった枝の局所対称性は保ち、空白の総面積ではなく各隙間の必要性を見る。
- SVGだから文字が読めるとは限らない。通常の表示幅で読めるかを確認し、拡大が必須なら「全体図＋機能別詳細」の二層構成にする。

## 6. 文字には優先順位をつける

1. 入出力・電源・主要制御信号。
2. 素子名と重要な中間ノード。
3. 素子値・W/L・m・nf。
4. 共通モデル・ボディ規約・実行履歴などの補足。

- 同じ種類のラベルは同じ側・同じ距離へ。本文・見出し・脚注を無関係に散らさない。ラベルを配線上に置かない。
- MOS名は所有する記号の脇、中心に近い高さから検討する。上下の空間へ一律に逃がすと別の段の名前に見えやすい。対応する左右の素子は鏡像の距離・高さにそろえる。ゲート線や隣の素子名と競合する場合だけ局所調整する。
- 受動素子の名前と値は近い2行として同じ端をそろえ、記号との組に見せる。図面がコンパクトになっても文字そのものを安易に小さくしない。
- 外部端子名は端子のそばへ、内部ノード名は所有する配線の上へ置く。端子名を内部接続点へ寄せすぎて入口・出口を無記名にしない。ラベル整理のために、了承済みの部品配置や配線を広げる前に文字の側・高さを調整する。
- このユーザーの既定表記：図中では `2k`、`2.5p`、`3M`、`10M` のように短く表示し、RはΩ、CはFと凡例で示す。メガは大文字 `M` とし、図中に `meg` を出さない。単位を付ける表では `3 MΩ` などでもよい。SPICEは大文字小文字を区別せず `M` もmilliと解釈するため、元データ・内部パラメーター・出力ネットリストの `meg` を表示のために `M` へ置換しない。表示と数値の一致を別途照合する。
- MOSの寸法は `W/L = 100/2 µm` のように凡例を含めて統一する。`m=4` と `nf=4` は区別し、幅の意味がモデル依存の場合は総幅と決めつけない。
- 図中の全サイズ表示が読みにくい場合は、読み取り用の簡潔な図と、全値を残した表／詳細図を併せる。ユーザーが全値表示を指定した場合は省略せず、図を分割または拡大する。
- `na` のような全内部ノード名を漫然と印字しない。省略するのは可視ラベルだけで、内部ネット名や接続は保持する。解析・照合に必要なら詳細図へ載せる。
- 通常の電源へのボディ接続は明確な共通注記のもとで省略表示できる。非標準のボディ接続、ボディ入力、別ウェル電源は描き、4端子の検証を必ず残す。

### このユーザーの近接ラベル配置

2026-10-11のATB修正版で使った、Analog Canvas 0.9.2の標準記号・文字サイズに対する開始値。画面ピクセルではなくネイティブ描画単位で、下向きが+y。別の記号、回転、文字幅、レンダラーでは実寸に合わせて調整する。字を小さくせず、必要な場所だけ離す。

| 対象 | 開始位置と整列 |
|---|---|
| MOS名 | インスタンス原点から右20・下5。左右反転なら左20・下5で右揃え。記号の中心脇へ置く |
| 縦向きR/Cの名前と値 | 原点から右16、名前は上4、値は下14。同じ左端の2行、行間18 |
| 横向きR/Cの名前と値 | 記号上の空間が使えるなら、中央揃えで名前は上32、値は上14の2行から試す。名前と値を上下に遠く分散しない。下側の方が空く場合はまとまりごと下へ移す |
| 入力端子名 | 端子の10上、中央揃え |
| 出力端子名 | 端子の14右・5下、左揃え |
| 内部ネット名 | 所有する水平線の8上。横位置は空いた線分に合わせる。ATBのn1/X/Gは接続点から50右、FBは35左を開始値にしたが、他回路へ固定流用しない |
| 電源名 | レールの起点から10右・8上 |

受動素子の名前と値のまとまり、左右MOS名の対称性、端子とラベルの対応を通常表示と拡大表示で確認する。自動の接触検査が0でも、文字が遠すぎて所有する素子や線が曖昧なら近づける。ラベル変更だけを求められた場合は部品と配線を維持する。

## 7. 前回のATB図をどう直すか

| 観察した問題 | 読む人への負担 | 次回の具体的変更 |
|---|---|---|
| OTAは8 MOS＋2受動素子に対して幅が広く、長い空の線が多い | 図全体に合わせると素子・文字が小さくなる | 差動対・負荷・出力を近づけ、レールと段間線を短くする。見出しを図の説明へ移す |
| OTAのミラー共通ゲートが大きく迂回する | 基準側とコピー側の関係を認識しにくい | 短いD–Gループと同じ高さの共通ゲート線を先に設計する |
| OTAの左下バイアスが大きな空白の端に孤立する | テール／出力電流との関係を同名ラベルから再構成する必要がある | バイアスを近接配置するか、明瞭な小ブロックに分ける。必要なミラー関係を優先配線する |
| LDOの主帰還が二つのFBラベルで分断される | 閉ループが図の形から分からない | 分圧点から誤差増幅器への帰還線の通路を、素子配置前に確保する |
| LDOのGラベルはパス駆動と適応バイアスの共有関係を隠す | 補助ループを見落としやすい | 可能なら連続配線し、主ループとの区別を配置／短い注記で示す |
| 生の数値・小さな分数・長い脚注が並ぶ | 拡大しないと何が重要か分からない | 工学表記、統一W/L表記、共通仕様の別表化。値を保持したまま表示を整理する |

これは元図が電気的に不正であるという指摘ではない。接続検証を通っていても、認識と追跡の負担が残っていた。

## 8. 人による確認用の採点表

各項目を0＝困難、1＝追えば分かる、2＝すぐ分かるで評価する。作者自身の暫定評価とユーザー評価を区別する。

| 項目 | 見るもの |
|---|---|
| 機能の形 | 差動対・ミラー・積み重ね・出力段が配置から分かる |
| 主経路 | 入力から出力、または指定された電流経路を連続して追える |
| 帰還・補償 | 戻り先とまたぐ段が明瞭。ループのある回路のみ適用 |
| 局所密度 | 関連素子は近く、別機能は適度に離れ、無意味な空白が少ない |
| 文字 | 想定表示サイズで素子名・値・端子名が読める |
| 接続の明瞭さ | 分岐と交差、隠したボディ、同名接続が曖昧でない |
| 配線の簡潔さ | 段間の不要な横→縦→横、ゲートごとの個別迂回、同じ位置へ戻る折返しを配置変更で除けないか確認した |

重要項目が0なら修正する。合計点だけで受け入れない。少数素子の回路で、端子位置合わせだけで減らせる迂回が残る場合は作図を続ける。配置変更を試さず「必要な曲げ」と判断しない。ユーザーから曲げの多さを指摘されたら、過去の自己評価よりその指摘を優先し、局所経路ごとに原因を再評価する。5秒で機能の位置、20秒程度で主経路を説明できるかはレビューの目安であり、実験で保証された閾値ではない。電気的同一性はこの採点とは別に必須で検証する。
