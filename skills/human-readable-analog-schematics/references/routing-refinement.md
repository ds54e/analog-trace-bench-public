# 配線の曲げを減らす：端子を合わせてから線を引く

## この補足が必要になった理由

2026-10-11のATB OTA/LDOの描き直しでは、差動対の形と連続した帰還は改善したが、ユーザーから「まだ無駄な配線の曲げが目立つ」と指摘された。以前の「機能単位で配置→主要ネットを連続配線」だけでは不足していた。同種MOSを広域に同じ高さへ置き、固定した部品間を曲がった線で埋めたことが原因の一つだった。

同日にログイン済みのAnalog Canvasギャラリーを `ai=0` で再検索し、小規模ミラー・5T OTA・2段増幅器を新たに8件、LDOを再度2件、計10件目視確認した。出典は末尾。観察から導いた作図判断であり、最適性の証明や元回路の電気検証ではない。

## 優先順位

**電気的同一性・明瞭な接続 → 回路の型と主要経路 → 不要な曲げ／折返しの削減 → 配線長・余白の調整。**

少ない曲げでも大きく迂回した線、最短でも回路記号を貫通する線は不適切。同名ラベルへ置き換えるだけでは配線を改善したことにならない。逆に、離れた補助バイアスまで全て実線にすることも目的にしない。

## 1. 端子とノードの高さを合わせる

- 段間では、送り側の縦配線上の取り出し点と、受け側のゲートを同じ高さにする。取り出し点は既存の同一ネット上で移動できる場合が多い。
- `横→縦→横` が出たら、まず受け側の素子を上下に動かす案を検討する。例えば入力段の出力が中段にあるなら、出力段PMOSまで最上段に揃える必要はない。
- 差動対や対応するカスコードは局所的な行揃えを保つ。独立した増幅段・駆動段・電流源の高さまで同じに固定しない。
- ミラーは共通ゲートを向き合わせ、同じ高さで接続する。電源／ドレインの縦枝と干渉しない向きを選ぶ。図形の左右反転でD/S/Bを交換しない。
- LDOでは分圧点FBの高さも自由度として扱う。R1/R2の寸法と上下の配線長を調整し、入力ゲートと直接つながる高さを検討する。抵抗値・並列容量の接続は変更しない。

## 2. 分岐は一本の幹線から取る

- 多端子ネットを、各端子から一つの任意の中心点へ折れ線で集めない。共通ゲート線・電源線・帰還線の主となる直線を先に置き、その途中から短い枝を出す。
- 三つ以上のゲートがある場合、共通線と各ゲートの入口方向を同時に検討する。素子ごとに似たコの字配線を作らない。
- T字の分岐点を既存の直線上へ置く。分岐点を置くためだけの小さな段差や箱形の迂回を作らない。
- 共通ゲートの水平線が別MOSの記号や無関係な端子を貫くなら、その直線化は不採用。全ゲートを同じ行にすれば必ず一本でつながるわけではない。共通線を一段ずらし、短い枝を使う案、素子の向きを変える案、非対応段をずらす案を比較する。

## 3. 曲げの役割を区別する

| 形／理由 | 判断 |
|---|---|
| 障害物がなく同じ行／列に向いた二端子 | 直線を第一候補。不要な上下・左右の折返しを残さない |
| 高さ・列が異なる二端子 | 端子の出口方向に合うL字をまず試す。難しければ端子位置を調整 |
| ゲートの入口方向や他の枝を避ける二曲げ | 必要な場合がある。位置・向き変更で減らせないか一度確認 |
| ミラーのダイオード接続D–G | 共通ゲートへの短い局所戻りは機能を表す。曲げゼロを求めて消さない |
| 差動対の共通ソースをテールへ集める形 | 型として必要な枝。左右の対応と明瞭な共通点を保つ |
| 主要帰還の外周経路 | 他の経路と区別できる必要分を残す。同じネット内に小さな余分な段差を重ねない |
| ラベルを避けるだけの曲げ | まずラベルの位置・側・情報量を変える |
| 端子から出て離れ、再び同じ高さ／列へ戻る小さなコの字 | 障害物・端子方向・機能の説明がなければ修正対象 |

「二曲げ以上は禁止」といった一律の制限は設けない。曲げ数には直線を複数のroute/legに分割しただけの境界やT分岐を数えず、実際の方向転換を見る。MOS記号自身の折れ線を配線の曲げ数に含めない。

## 4. 配線後の簡素化パスを必ず入れる

小規模回路では各段間接続、共有ゲート、補償枝、主帰還を順に確認する。

1. 端から端まで追い、理由が説明できない曲げ、逆戻り、反復したゲート引込線を候補として挙げる。
2. **取り出し点を同じネット上で移す → 分岐点を幹線上へ移す → ラベルを移す → 受け側素子を移す／鏡像にする → 局所グループを移す** の順を目安に検討する。対称性や型を壊すなら別案を選ぶ。
3. 候補と元の経路を比べる。曲げと逆戻りが減り、記号貫通・誤接続・曖昧な交差・過密ラベルが増えない案を採用する。単に曲がり角を遠くへ移す変更は改善と数えない。
4. SVGを再描画し、記号の入口と直線上の分岐を確認する。ネイティブの接続／値／端子順検証を繰り返す。
5. 残した目立つ迂回には「この枝を回避」「主要帰還を分離」「局所D–G接続」のような具体的理由を持つ。全ての角を説明文で埋める必要はないが、無理由の曲げを自己採点で合格にしない。

自動補助を使う場合、同じピン間の幾何学的な曲げ数、同じ高さへ戻る区間、共有線への重複した引込を候補抽出に使う。総線長やManhattan距離との差だけでは必要なピン回避と無駄な迂回を区別できないため、自動合否にはしない。

## 6. 接続する十字をT字へ分け、補償を独立した枝として読む

2026-10-11、第3版へのユーザー指摘：「4線の交差は少しずらして3線と3線にする。ドットに注意しないと読めない形を避けたい」。このユーザーの作図方針として適用し、一般規格やギャラリーからの結論とは区別する。

- 同一ネットの四方向接続は二つのT字に分ける。例えば幹線へ上から入る枝と下から出る枝の位置をずらす。二つの点が重ならず判別できる最小限のずれから始める。第4版の40座標単位はユーザーに「ずらしすぎ」と指摘された。第5版では10へ縮めたが、この数値を別レンダラーへ固定適用しない。
- 分圧器の抵抗など、機能を示す共通軸を崩さない。LDOではR1/R2を同じ縦列へ近接配置し、FB取り出しとCFFの下側接続だけを縦方向に少しずらす。文字を置く空間と分岐の微小なずれを混同しない。
- 同一直線のroute分割は分岐ではない。実際の上下左右の導線の有無を調べる。分岐位置だけを動かす際も、別ネットへの接触や記号貫通を再検査する。
- 非接続の十字を二つのT字にすると誤接続になる。配置変更や通路の選び直しで減らし、過大な迂回が必要なら非接続交差として残す。接続十字がなければ、十字形は一貫して非接続と読める。
- Miller補償のRCは、主信号経路に埋もれない独立した枝にする。段の入力側と出力側をまたぐ関係を優先し、縦のRC枝、上側／下側の帰還経路を比較する。素子順・途中ノードは変えない。横のRCが常に不自然という規則にはしない。
- 余白も作例と比較する。2026-10-11の再確認では、LDO作例 pes3mh8swm / 8qatzztvzk の縦に近接した分圧器、OTA作例 vys6p4zc7s / x5jaqe94t7 の局所的なまとまりを参考にした。値表記を省いた作例の密度はそのままコピーせず、実際のラベル幅を確保する。電気的照合と幾何検査の結果は描画出力に保存する。
